A Problem Worth Solving

Understanding the environmental challenge behind EcoDrop.

Improper E-Waste Disposal

Discarded mobile phones, computers, chargers and batteries are forms of electronic waste. Improper handling can contribute to soil and water pollution and cause valuable materials to be lost instead of recovered.

Our Proposed Solution

EcoDrop is a student-designed digital guide that lets users enter their e-waste details, receive basic disposal guidance and search for possible collection facilities using their location.

Technology Behind EcoDrop

Affordable technologies suitable for a student prototype.

HTML5 Page structure
CSS3 Design and layout
JavaScript Validation and processing
Google Maps Search Location discovery
These technologies are affordable and easy to implement. The prototype runs in a browser and requires no database, paid API key or XAMPP server.

How EcoDrop Works

A clear workflow from user information to disposal guidance.

INPUT

Share Details

The user selects an e-waste category, enters the quantity and provides a city or PIN code.

PROCESSING

Validate and Search

JavaScript validates the information and prepares a location-based search query.

OUTPUT

Receive Guidance

The webpage displays the entered details, safe disposal advice and a collection-centre search link.

Information and Data Sources

The data needed to provide relevant disposal guidance.

📝

User Input

E-waste type, item quantity and city or PIN code entered directly by the user.

🗺️

Location Search

Google Maps search results can help identify possible collection locations. Results require independent verification.

🏢

Official Sources

CPCB, State Pollution Control Boards and official recycler websites can be consulted to verify facility authorisation.

Prototype limitation: EcoDrop does not maintain its own verified recycler database or save submitted registrations. It creates a search link using the user's location.

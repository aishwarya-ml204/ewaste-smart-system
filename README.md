
# 🌱 EcoDrop – Smart E-Waste Collection Guide

## Project Overview

EcoDrop is a student-proposed digital solution designed to encourage the safe and responsible disposal of electronic waste (e-waste).

Electronic waste includes discarded mobile phones, chargers, computers, batteries, and earphones. Improper disposal can contribute to environmental pollution and the loss of valuable recoverable materials.

EcoDrop provides a simple webpage where users can enter their e-waste details, view disposal guidance, and search for possible collection facilities based on their location.

## Environmental Problem

Improper disposal of electronic waste is the selected environmental problem.

Electronic items discarded with ordinary household waste may be handled unsafely, contributing to pollution and preventing the recovery of reusable materials.

## Proposed Digital Solution

EcoDrop is a lightweight, browser-based website that helps users:

- Select the type of electronic waste.
- Enter the quantity of waste.
- Provide a city name or PIN code.
- Receive basic disposal and safety guidance.
- Open a Google Maps search for possible e-waste collection facilities.

This is an original student prototype, not a description of an existing application.

## Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Creates the webpage structure and form |
| CSS3 | Provides styling, layout, and responsive design |
| JavaScript | Validates user input and generates disposal guidance |
| Google Maps Search | Helps users search for possible collection facilities |

The prototype does not require a database, XAMPP server, or paid API key.

## Input Data and Sources

### Input Data

- Type of electronic waste
- Quantity of items
- User-entered city or PIN code

### Possible Data Sources

- **User input:** E-waste type, quantity, and location entered into the webpage.
- **Google Maps search:** Location-based results for possible collection facilities.
- **Official sources:** Central Pollution Control Board (CPCB), State Pollution Control Boards, and official recycler websites for checking facility authorisation.

Google Maps results are not automatically verified by this prototype. Users should confirm that a facility is authorised and accepts their type of waste before visiting.

## System Workflow

The system follows the required Input → Processing → Output model.

### 1. Input

The user selects the e-waste category, enters the quantity, and provides a city name or PIN code.

### 2. Processing

JavaScript validates the form details and generates a location-based search query.

### 3. Output

The webpage displays the entered information, disposal guidance, safety advice, and a link to search for possible collection facilities.

## Expected Environmental Benefits

1. **Reduced pollution:** Encourages responsible e-waste disposal.
2. **Soil and water protection:** Promotes safer handling of electronic waste.
3. **Resource recovery:** Encourages recycling and reuse of valuable materials.
4. **Environmental awareness:** Educates users about responsible e-waste management.
5. **Convenient disposal search:** Helps users discover possible collection facilities.

## Prototype Features

- Responsive, single-page website.
- E-waste registration form.
- Client-side form validation.
- Disposal and safety guidance.
- Google Maps search link.
- Environmental benefits information.
- Data source and project information sections.

## Prototype Limitations

- The website does not save registrations.
- No user account or database is implemented.
- Collection-centre search results are not independently verified.
- The prototype does not automatically confirm recycler authorisation.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Enter sample e-waste details and test the form.

No additional software or server is required.
